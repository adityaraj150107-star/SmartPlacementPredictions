    PROJECT INFORMATION

    About Smart Placement Predictions

    This section is the common project information page for students and administrators.

    🎯

    Smart Placement Predictions

    An AI-assisted placement platform that combines student profiles, machine learning prediction, resume analysis and a multi-tool AI workspace in one system.

    🤖 AI & Agent Features

    • One Smart Placement AI Agent
    • File/photo upload and personal library
    • Web search and deep research
    • Image generation and sketch attachment
    • Interactive visualization
    • Project, study, coding and placement assistance

    🧠 ML & AI Technologies

    • Random Forest placement prediction
    • Campus placement dataset
    • Ollama local LLM support
    • Gemini cloud fallback/support
    • PDF text extraction for resume review
    • AI-assisted recommendations

    💻 Technology Stack

    • Python
    • FastAPI backend
    • Flask frontend/proxy
    • HTML, CSS, JavaScript
    • SQLite database
    • REST APIs and session authentication

    🔐 Accounts & Security

    • Student registration and login
    • Email OTP verification
    • Password reset flow
    • Persistent database sessions
    • Role-based Admin / Student access
    • Per-user private file library

    👨‍🎓 Course Coverage

    • BCA
    • MCA
    • MBA
    • B.Tech / BE
    • BBA / B.Com
    • B.Sc / M.Sc and other courses

    📈 Placement Workflow

    1. Register / Login
    2. Complete student profile
    3. Run ML prediction
    4. Analyze resume
    5. Ask AI Agent for improvement
    6. Prepare skills, interviews and projects

    What the project is designed to solve

    It brings student information, placement prediction, resume analysis, AI assistance, research and project preparation into one accessible platform so students and administrators can understand and manage the placement workflow from a single dashboard.
