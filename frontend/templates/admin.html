Smart Placement Predictions

AI-assisted placement platform combining student profiles, four ML algorithms with accuracy history, resume analysis, one Smart Placement AI Agent, research tools and project preparation.

  • One project-aware Smart Placement AI Agent
  • Files & personal library
  • Web search and deep research
  • Image creation, sketch and visualization

🧠 ML

  • Random Forest model
  • Campus placement dataset
  • Academic + aptitude + internship features
  • Probability, status and improvement tips

💻 Stack

  • Python, FastAPI and Flask
  • HTML, CSS and JavaScript
  • SQLite database
  • REST APIs, sessions and OTP verification

  • BBA / B.Com
  • B.Sc / M.Sc and other courses

  • Admins manage accounts and platform activity
  • Private per-user file library
